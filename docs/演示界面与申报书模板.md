## 一、演示界面（Gradio，最快出效果）

### 1.1 目标

一个网页：上传图片/视频 → 选模型（基线 vs 压缩模型）→ 显示检测框 + 置信度 + **参数量/FPS 对比**。用于答辩现场演示 + 录屏。

### 1.2 代码（存 `scripts/30_demo_ui.py`）

```python
# -*- coding: utf-8 -*-
"""DGAP 演示界面：上传图 -> 选模型 -> 显示检测结果 + 指标对比"""
import gradio as gr
from ultralytics import YOLO

# 模型清单：填成员1 跑出来的实际路径（best.pt）
MODELS = {
    "Baseline(YOLOv8s)": "runs/baseline/yolov8s/weights/best.pt",
    "普通剪枝": "runs/finetune/uniform_r0.5/weights/best.pt",
    "DGAP自适应剪枝": "runs/finetune/dgap_r0.5/weights/best.pt",
    "自适应剪枝+蒸馏": "runs/distilled/student_distilled.pt",
}

_cache = {}
def get_model(name):
    if name not in _cache:
        _cache[name] = YOLO(MODELS[name])
    return _cache[name]

def detect(image, model_name, conf):
    import time, numpy as np
    model = get_model(model_name)
    t0 = time.time()
    results = model.predict(image, conf=conf, imgsz=640, verbose=False)[0]
    fps = 1 / (time.time() - t0 + 1e-6)
    # 画框
    plot = results.plot()
    # 指标
    n_param = sum(p.numel() for p in model.model.parameters()) / 1e6
    info = f"模型: {model_name}\n参数量: {n_param:.2f}M\n本次推理: {fps:.1f} FPS\n检出目标: {len(results.boxes)} 个"
    return plot, info

def compare(image, conf):
    """基线 vs 压缩模型 同屏对比"""
    imgs, infos = [], []
    for name in MODELS:
        img, info = detect(image, name, conf)
        imgs.append(img)
        infos.append(info)
    return imgs[0], imgs[1], imgs[2], imgs[3], "\n\n".join(infos)

with gr.Blocks(title="DGAP 电力缺陷检测系统") as demo:
    gr.Markdown("# 面向电力边缘设备的缺陷感知自适应轻量化检测系统")
    with gr.Tab("单模型检测"):
        with gr.Row():
            inp = gr.Image(type="numpy", label="上传图片")
            with gr.Column():
                model_name = gr.Dropdown(list(MODELS), value=list(MODELS)[0], label="模型")
                conf = gr.Slider(0.05, 0.9, 0.25, label="置信度阈值")
                btn = gr.Button("检测")
        out_img = gr.Image(type="numpy", label="结果")
        out_info = gr.Textbox(label="指标")
        btn.click(detect, [inp, model_name, conf], [out_img, out_info])
    with gr.Tab("基线 vs 压缩 对比"):
        with gr.Row():
            inp2 = gr.Image(type="numpy", label="上传图片")
            conf2 = gr.Slider(0.05, 0.9, 0.25, label="置信度阈值")
        with gr.Row():
            c0 = gr.Image(type="numpy", label="Baseline")
            c1 = gr.Image(type="numpy", label="DGAP剪枝")
            c2 = gr.Image(type="numpy", label="剪枝+蒸馏")
            c3 = gr.Image(type="numpy", label="普通剪枝")
        cinfo = gr.Textbox(label="指标对比")
        gr.Button("对比").click(compare, [inp2, conf2], [c0, c1, c2, c3, cinfo])

demo.launch()
```

## 二、申报书填写模板（B3 表）

### B3-1 作品设计、发明的目的和基本思路，创新点，技术关键和主要技术指标

**目的**：电力线路巡检缺陷（破损绝缘子、销钉缺失）依赖人工/云端，算力受限的边缘设备跑不动高精度检测模型。本项目把缺陷检测模型轻量化到能上树莓派实时跑，精度不显著下降。

**基本思路**：电力缺陷数据集 → 训练高精度 YOLO 模型（教师）→ 缺陷感知敏感性分析 → 自适应混合粒度剪枝量化 → 缺陷区域知识蒸馏 → ONNX 导出 → 树莓派实时检测。

**创新点**（三条，见 `问题和要求.md`）：
1. 分层特征贡献度评估 + 自适应混合粒度剪枝量化联合优化（不全局一刀切，保护小目标缺陷通道）。
2. 面向电力小目标缺陷的加权蒸馏损失（小目标锚定权重 + 困难样本加权）。
3. 端到端自动化边缘部署工具链（训练→压缩→导出→评估一键完成）。

**技术关键**：C2f 重参数化剪枝、缺陷感知重要性打分、通道对齐蒸馏、混合精度导出。

**主要技术指标**：参数量压缩 ≥60%、推理速度提升 ≥2.2 倍、mAP@0.5 下降 ≤3%。

### B3-2 作品的科学性先进性（必须写，附技术分析 + 参考文献）

> 模板：逐条"现有技术缺陷 → 本作品改进 → 量化进步 + 参考文献"

| 现有技术 | 缺陷 | 本作品改进 | 显著进步 | 参考文献 |
|---|---|---|---|---|
| 全局统一剪枝/量化 | 对小目标"一视同仁"，压缩后小缺陷精度暴跌 | 基于 BN 缩放因子+激活响应评估各层对缺陷的贡献度，缺陷敏感层低剪枝/高位宽，冗余层高剪枝/低位宽 | 同压缩比下小目标 mAP 高 5~8% | Network Slimming (Liu ICCV'17)；torch_pruning |
| 通用知识蒸馏 | 只模仿整体输出，小目标/少数类被淹没 | 缺陷区域加权 + 小目标锚定权重 + 困难样本动态加权 | 压缩后小目标漏检率下降 | Hinton KD；TAL/任务对齐蒸馏 |
| 纯算法研究 | 无落地工具，工程门槛高 | 端到端工具链一键生成 ONNX 部署文件 | 从"算法"到"可用工具" | ONNX Runtime；TensorRT |
