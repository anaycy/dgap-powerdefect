# 电力缺陷数据集采集方案（竞赛用）

> 目标：**1500～3000 张原图**，做完离线增强后等效上万样本，够训练、对比实验、写申报书。
> 核心难点不是"图片总量"，而是**小缺陷样本（绝缘子破损、销钉缺失）占比少**——这是实验成败的关键，本方案重点解决它。

---

## 一、先想清楚：做什么类别（这决定数据怎么组合）

建议做一个 **2~3 类的组合**，既贴合"电力特色"又有小目标亮点，学术上完全站得住：

| class_id | 类别 | 说明 | 数据来源 |
|---|---|---|---|
| 0 | broken_insulator 破损绝缘子 | 已有 iraset 909 张，再扩充 | iraset / CPLID / CPMID / Roboflow / Mendeley |
| 1 | missing_pin 销钉缺失 | **小目标难点，重点补** | 腾讯云/CSDN 销钉数据集（见 §三） |
| 2 | (可选) flashover 污闪 / normal 正常绝缘子 | 让模型学会区分"有缺陷 vs 正常" | 华为云 12000 张 / Mendeley 4 类 |

> 若时间紧：**只做 0+1 两类**（破损绝缘子 + 销钉缺失）也完全够申报书；两类正好覆盖"大目标缺陷 + 小目标缺陷"两个层次，对比实验更有说服力。

> **重要**：上面前 4 个"红外数据集"是**设备部件检测**（识别避雷器/套管/断路器在哪），和你的"缺陷检测"是**两个不同任务**，不能直接混进缺陷检测数据集里一起训。
> - 想"红外 + 缺陷检测"→ 用 **LIIID**（绝缘子异常发热，小目标）或 **BNUT**（变压器故障分类）。
> - 想"红外作为独立场景加分项"→ 单独立一个红外设备检测模块，作为系统"多场景巡检"的展示，别和缺陷检测的类别混。

### 类别统一（多数据集合并前必须做，否则 class_id 对不上）

不同数据集类别名不同，合并前**先定一张统一类别表**，再用 `22_voc2yolo.py` 的 `--classes` 按同一顺序映射。建议缺陷检测就固定这几个：

| 统一 class_id | 含义 | 来自哪些数据集 |
|---|---|---|
| 0 | broken_insulator 破损绝缘子 | iraset / CPLID 缺陷 / Mendeley Broken / Roboflow |
| 1 | missing_pin 销钉缺失 | 腾讯云销钉数据集(DefectPin/pin_missing) |
| 2 | normal 正常(可选，做正负样本对比) | CPLID 正常 / 销钉 NormalPin |

> 若数据集里有多余类别（如污闪、脏污、正常绝缘子），要么映射进上面 3 类，要么删掉对应样本——**别让一个 class_id 在训练里一会是"破损"一会是"污闪"**。

## 三、小缺陷样本：手把手教程（重点）

**为什么难**：销钉缺失/破损区域通常只有几十像素，占整图 <1%，公开数据集里框少、还容易被大目标样本淹没。所以要么**找现成的销钉数据集**，要么**自己标/自己合成**。按从省事到进阶排序：

### 路线 1：直接用现成销钉数据集（最省事，推荐）

1. 打开 §二-B 的腾讯云/CSDN 链接，找到文章里的**百度网盘链接 + 提取码**，下载解压。
2. 看解压后是 `xml` 标注还是 `txt` 标注：
   - 是 `xml`（VOC）→ 用下面命令转 YOLO：
     ```bash
     .venv/Scripts/python.exe scripts/22_voc2yolo.py \
         --xml-dir <解压的Annotations目录> --img-dir <解压的JPEGImages目录> \
         --classes "DefectPin,NormalPin,DefectInsulator,NormalInsulator"
     ```
     （`--classes` 按你最终类别顺序填，保持一致）
   - 已是 `txt`（YOLO）→ 直接用，跳过转换。
3. 把图片/标签拷进 `data/images/_raw`、`data/labels/_raw`（合并多个数据集用）。
4. 在 Roboflow Universe 搜 [insulator damage](https://universe.roboflow.com/search?q=class:insulator+damage) 也能找到销钉/金具缺陷数据集，用 Roboflow 直接下 YOLO 格式最省心。

### 路线 2：Roboflow Universe 搜现成（一键下载，格式干净）

1. 注册 [Roboflow](https://app.roboflow.com/)（免费，拿 API key）。
2. 在 [Universe 搜索页](https://universe.roboflow.com/search?q=class:insulator+damage) 搜 `insulator`、`pin missing`、`transmission line`。
3. 挑一个**许可证 CC BY 4.0**、类别对得上、图片量够的数据集，点 "Download Dataset" → 选 `YOLOv8` 格式。
4. 用代码下载（换成你自己的 key 和项目/版本号）：
   ```python
   from roboflow import Roboflow
   rf = Roboflow(api_key="你的KEY")
   ds = rf.workspace("insulator-dataset").project("insulator-defect-yysit").version(2).download("yolov8")
   ```
5. 下载后得到 `train/valid/test` 三目录（YOLO 格式），把图片并进 `data/images/_raw`、标签并进 `data/labels/_raw`。

### 路线 3：自己标注（图片不难找，但要花时间标）

适合补充公开数据集里没有的类别（比如特定角度的销钉缺失）。

1. 找图：无人机/直升机巡检图、输电线路特写图，在百度图片 / 学术论文附图里搜"输电线路 销钉""绝缘子 缺陷 无人机巡检"。目标 300～500 张。
2. 标注工具（二选一）：
   - [labelImg](https://github.com/HumanSignal/labelImg)：本地轻量，画框 → 存 YOLO txt。
   - [label-studio](https://labelstud.io/)：网页版，多人协作、半自动（SAM 辅助），导出 YOLO 格式。
3. 标注规范：小缺陷也画**最小外接框**，归一化坐标；同类别名称统一。

### 路线 4：合成小缺陷样本（贴图，最进阶，弥补极端稀缺）

当某类缺陷（如"销钉缺失"）图确实找不到时，可以**贴图合成**：把"缺陷区域"小块贴到正常图上。

- 思路：收集一批"缺销钉"的特写小图（或人工在正常金具图上挖掉销钉区域），按透视/角度贴到正常杆塔/绝缘子图上，自动生成框标注。
- 这是学术界常见的 data augmentation（copy-paste / Cut-Paste），能显著缓解小样本。具体脚本可让我按你的素材再写（需要你提供"正常图"和"缺陷小块"两类素材）。

## 四、数据增强（重点补小目标）

分两层：

1. **离线增强**（本脚本，冲量 + 过采样小缺陷）：
   ```bash
   .venv/Scripts/python.exe scripts/21_augment_dataset.py --split train \
       --small-area 0.005 --small-multiplier 4 --normal-multiplier 1
   ```
   对**含小目标（bbox 面积 <0.5%）的图**做 4 倍增强（旋转/缩放/亮度/翻转），普通图 1 倍——把小缺陷样本虚拟放大到和大目标相当。

2. **在线增强**（训练时自动，无需手动）：ultralytics 训练自带 mosaic、HSV、缩放、翻转。但**对小目标场景建议关掉或减小 mosaic**，否则小目标容易被拼图糊掉，可加 `--close-mosaic 10`（最后 10 轮关 mosaic）。

## 五、7:2:1 划分（补出 test 集）

当前项目只有 train/val，没有 test。跑：

```bash
# 把现有 train+val 合并后重新 7:2:1 分层划分（会自动生成 test 集）
.venv/Scripts/python.exe scripts/20_split_dataset.py --stratify

# 或者：把刚下载合并好的平铺数据集划分
.venv/Scripts/python.exe scripts/20_split_dataset.py \
    --src-img data/images/_raw --src-label data/labels/_raw --stratify
```

`--stratify` 按类别分层，保证"销钉缺失"这种稀有类在 train/val/test 三个集里都有。

## 六、从下载到训练：完整流程（照做）

```bash
# 1) 下载并合并数据集（见 §二、§三），把图片/标签统一放到 data/images/_raw + data/labels/_raw
#    （VOC 的先跑 22_voc2yolo.py 转 YOLO）

# 2) 7:2:1 划分
.venv/Scripts/python.exe scripts/20_split_dataset.py --src-img data/images/_raw --src-label data/labels/_raw --stratify

# 3) 改 data/data.yaml 的 names/nc 为最终类别（顺序要和 22_voc2yolo.py 的 --classes 一致）

.venv/Scripts/python.exe scripts/21_augment_dataset.py --split train --small-multiplier 4

# 5) 验证数据对齐（图片与标签同名、类别不越界）
.venv/Scripts/python.exe scripts/02_metrics.py --weights runs/baseline/yolov8s/weights/best.pt --data data/data.yaml --method "检查"
# 或直接重新训练 baseline
```

## 七、避坑

- **图片和标签同名**，且标签框坐标是**归一化 0~1**（`cx cy w h`），不是像素。
- **多数据集合并**时，`class_id` 必须统一——用 `22_voc2yolo.py` 的 `--classes` 显式指定，别用自动字母序。
- **test 集别做增强、别参与训练**，否则数据泄漏，评委一查就穿帮。
- **小缺陷的 bbox 别画太大**：画最小外接框，否则"小目标"变成"大框"，模型学不到精细定位。
- 腾讯云/CSDN 链接是网盘，可能失效；失效优先去 Roboflow Universe 搜替代。
