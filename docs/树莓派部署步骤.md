# 树莓派部署步骤（成员2 手把手）

> 目标：把成员1 训练/剪枝/量化后的 YOLOv8 模型部署到**树莓派5（8GB）+ 摄像头**，
> 实现本地实时电力缺陷检测，作为申报书"实物、产品"参展 + 边缘部署创新点的实证。
>
> 硬件：树莓派 5（8GB）+ 摄像头（USB 摄像头 或 CSI Camera Module 3）+ ≥32GB SD 卡 + 27W 电源。

---

## 0. 为什么用树莓派5 + ONNX Runtime

- 树莓派5 是 **ARM64（4 核 Cortex-A76）**，不能跑 CUDA/TensorRT（那是 Jetson 的 NVIDIA GPU 才能用）。
- 部署方案选 **ONNX Runtime（CPU）**：直接加载 `.onnx` 模型，CPU 推理，最简单稳定。
- 成员1 的 `13_quantize_export.py` 会导出 **fp32 和 fp16 两个 ONNX**。树莓派 CPU 上：
  - **fp32 用 onnxruntime 直接跑**（基线）；
  - **fp16 在 CPU 上基本没加速**（fp16 是给 GPU/Jetson 用的），别用它；
  - 想更快，把 fp32 模型用 onnxruntime 动态量化成 **int8**（见 §7），CPU 上能再快一截。

## 4. 完整推理脚本（贴到树莓派跑）

把下面存成 `~/dgap/detect.py`。它做了：letterbox 前处理 → ONNX 推理 → 阈值 + NMS 后处理 → 画框。

```python
# -*- coding: utf-8 -*-
"""树莓派 YOLOv8 ONNX 推理（单张图 / 摄像头实时）"""
import cv2
import numpy as np
import onnxruntime as ort

MODEL = "best_fp32.onnx"     # 改成你的 ONNX 文件名
IMGSZ = 640
CLASSES = ["broken_insulator", "missing_pin"]   # 和 data.yaml 一致
CONF = 0.25
IOU = 0.45

session = ort.InferenceSession(MODEL, providers=["CPUExecutionProvider"])
in_name = session.get_inputs()[0].name


def letterbox(img, size=IMGSZ, color=(114, 114, 114)):
    h, w = img.shape[:2]
    r = min(size / h, size / w)
    nw, nh = int(round(w * r)), int(round(h * r))
    img = cv2.resize(img, (nw, nh), interpolation=cv2.INTER_LINEAR)
    dw, dh = (size - nw) // 2, (size - nh) // 2
    img = cv2.copyMakeBorder(img, dh, size - nh - dh, dw, size - nw - dw,
                             cv2.BORDER_CONSTANT, value=color)
    return img, r, (dw, dh)


def detect(img):
    """输入 BGR 图，返回 [(x1,y1,x2,y2, conf, cls), ...]（原图坐标）。"""
    img0 = img.copy()
    img, r, (dw, dh) = letterbox(img)
    blob = np.ascontiguousarray(img[:, :, ::-1].transpose(2, 0, 1)).astype(np.float32) / 255.0
    blob = blob[None]

    out = session.run(None, {in_name: blob})[0]        # (1, 4+nc, 8400)
    pred = out[0].transpose()                          # (8400, 4+nc)
    boxes = pred[:, :4]                                # xyxy（640 空间）
    scores = pred[:, 4:]                               # 各类别分数（已 sigmoid）

    results = []
    for c in range(len(CLASSES)):
        sc = scores[:, c]
        keep = sc > CONF
        if not keep.any():
            continue
        cb, cs = boxes[keep], sc[keep]
        idx = cv2.dnn.NMSBoxes(cb.tolist(), cs.tolist(), CONF, IOU)
        for i in (idx.flatten() if len(idx) else []):
            x1, y1, x2, y2 = cb[i]
            # un-letterbox 回原图坐标
            x1 = (x1 - dw) / r; y1 = (y1 - dh) / r
            x2 = (x2 - dw) / r; y2 = (y2 - dh) / r
            results.append((int(x1), int(y1), int(x2), int(y2), float(cs[i]), c))
    return results


def draw(img, results):
    for x1, y1, x2, y2, conf, c in results:
        cv2.rectangle(img, (x1, y1), (x2, y2), (0, 0, 255), 2)
        label = f"{CLASSES[c]} {conf:.2f}"
        cv2.putText(img, label, (x1, y1 - 5), cv2.FONT_HERSHEY_SIMPLEX, 0.6, (0, 0, 255), 2)
    return img


if __name__ == "__main__":
    # 单张图测试
    img = cv2.imread("test.jpg")
    res = detect(img)
    print("检测到", len(res), "个目标")
    for r in res:
        print("  ", CLASSES[r[5]], f"conf={r[4]:.2f}", r[:4])
    cv2.imwrite("result.jpg", draw(img, res))
```

跑通单张图后，就能确认模型在树莓派上正常工作。

## 5. 摄像头实时检测

### 5.1 摄像头启用

  （OpenCV 直读 CSI 在 Bookworm 上有时要配合 `picamera2`，**演示建议直接用 USB 摄像头最省事**。）

### 5.2 实时循环（加到 detect.py）

```python
def realtime():
    cap = cv2.VideoCapture(0)
    import time
    while True:
        t0 = time.time()
        ok, frame = cap.read()
        if not ok:
            break
        res = detect(frame)
        frame = draw(frame, res)
        fps = 1 / (time.time() - t0 + 1e-6)
        cv2.putText(frame, f"FPS {fps:.1f}", (10, 30),
                    cv2.FONT_HERSHEY_SIMPLEX, 1, (0, 255, 0), 2)
        cv2.imshow("DGAP", frame)
        if cv2.waitKey(1) & 0xFF == ord("q"):
            break
    cap.release()
    cv2.destroyAllWindows()
```

## 7. （可选）int8 量化再提速

树莓派 CPU 上 int8 比 fp32 快。用 onnxruntime 把 fp32 模型动态量化：

```bash
pip3 install onnxruntime onnx
```

```python
from onnxruntime.quantization import quantize_dynamic, QuantType
quantize_dynamic("best_fp32.onnx", "best_int8.onnx", weight_type=QuantType.QUInt8)
```

然后用 `best_int8.onnx` 替换脚本里的模型路径，FPS 会更高。**注意**：动态量化是"权重量化"，精度略降，记得在 val 上重测 mAP 确认没掉太多。

## 9. 常见坑

| 现象 | 处理 |
|---|---|
| `onnxruntime` 装不上 | 确认是 64 位系统；`pip3 install --no-cache-dir onnxruntime` |
| 输出形状对不上（不是 8400） | 模型 imgsz 不同，脚本 `IMGSZ` 改成导出时的值 |
| 检测框全错位 | 前处理 letterbox 的 `(dw,dh)/r` 和后处理 un-letterbox 要对上 |
| 摄像头打不开 | USB 摄像头换端口；CSI 用 `libcamera-hello` 先验证 |
| CPU 满载发热降频 | 加风扇，或把 imgsz 降到 480/416 |
