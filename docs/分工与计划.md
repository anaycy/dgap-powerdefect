# 分工与计划（发给组员）

> 项目：软硬结合·边端自治·闭环诊断的电力缺陷边缘智能系统
> 竞赛：第三届"明理杯"上海电力大学大学生课外学术科技作品竞赛 · 科技发明制作 B 类
> 团队：3 人 · 集体项目

---

## 一、项目一句话

软硬结合，把电力缺陷检测模型轻量化下沉到边缘设备，并形成「采集 → 检测 → 分级 → 预警 → 工单」闭环诊断。

**当前状态**：数据集已建成（3095 张、2 类）；核心算法代码已调通；已新增闭环诊断/融合/网关/部署平台模块（见 README）。待做——baseline 重训、树莓派部署、演示界面、申报材料。

### 成员1：算法负责人（任务清单）

- [ ] 重训 baseline（2 类 3095 张，100 轮）→ `runs/baseline/yolov8s/weights/best.pt`

- [ ] 每个方法跑 `02_metrics.py` + `03_make_table.py`，攒出**消融实验对比表**

**核心命令**（详见 `进度记录.md` 或 `../README.md`）：

```bash
.venv/Scripts/python.exe scripts/01_train_baseline.py --epochs 100
.venv/Scripts/python.exe scripts/02_metrics.py --weights runs/baseline/yolov8s/weights/best.pt --data data/data.yaml --method "Baseline(YOLOv8s)"
.venv/Scripts/python.exe scripts/03_make_table.py
```

## 五、关键提醒（避坑）

1. **评审看的是"真问题 → 方法改进 → 实验数据证明"**，消融实验表是灵魂，一定不能少。
2. **实物是硬性要求**：树莓派必须真跑起来，别用"模拟"糊弄（板卡模拟器只用于无 PCB 时联调）。
3. **合规性**：成果必须标注为课外完成，不与课程作业重复；3 人团队合规（≤8 人）。
4. **别编造获奖**；软著/校内展示是合法的"鉴定/展示"佐证。
5. 导师/推荐者（高级职称）尽早联系，申报需要他们签字。
6. **软硬结合是今年新亮点**：硬件板卡做不出来的部分如实写进申报书"实验室阶段"，别过度承诺。
