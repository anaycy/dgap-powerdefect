# 分工与计划（发给组员）

> 项目：面向电力边缘设备的缺陷感知自适应轻量化检测系统
> 竞赛：第三届"明理杯"上海电力大学大学生课外学术科技作品竞赛 · 科技发明制作 B 类
> 团队：3 人 · 集体项目

---

## 一、项目一句话

把 YOLO 目标检测模型针对**电力缺陷**（破损绝缘子、销钉缺失）做**自适应剪枝 + 缺陷区域蒸馏 + 混合精度量化**，在精度几乎不掉的前提下压缩模型、提速推理，并部署到**树莓派**边缘设备实时检测。

**当前状态**：数据集已建成（3095 张、2 类）；核心算法代码已调通；待做——baseline 重训、树莓派部署、演示界面、申报材料。

## 五、科学性先进性怎么写（B3 核心）

套用三个创新点，每个都写成「现有技术缺陷 → 我的改进 → 可量化进步」：

| 现有技术缺陷 | 我的改进 | 显著进步 |
|---|---|---|
| 全局统一剪枝/量化，对小目标"一视同仁"→ 小缺陷精度暴跌 | 分层特征贡献度评估 + 自适应混合粒度剪枝量化 | 同压缩比下小目标 mAP 高 5~8% |
| 通用蒸馏只模仿整体输出 → 小目标漏检 | 小目标锚定权重 + 困难样本加权 | 压缩后小目标漏检率下降 |
| 只停在算法精度，无落地工具 | 端到端自动化工具链 → 边缘部署 | 一键生成可部署文件 |

**参考文献方向**：① 结构化剪枝（Network Slimming / torch_pruning）；② 知识蒸馏（Hinton KD）；③ 量化感知训练（QAT）；④ 电力缺陷检测（YOLOv5/v8 绝缘子/销钉检测论文）；⑤ 边缘部署（ONNX Runtime / TensorRT）。

## 七、关键提醒（避坑）

1. **评审看的是"真问题 → 方法改进 → 实验数据证明"**，消融实验表是灵魂，一定不能少。
2. **实物是硬性要求**：树莓派必须真跑起来，别用"模拟"糊弄。
3. **合规性**：成果必须标注为课外完成，不与课程作业重复；3 人团队合规（≤8 人）。
4. **别编造获奖**；软著/校内展示是合法的"鉴定/展示"佐证。
5. 导师/推荐者（高级职称）尽早联系，申报需要他们签字。
